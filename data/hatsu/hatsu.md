## Overview

Hatsu is a bridge that interacts with the Fediverse on behalf of your static site.

## Features

- Fediverse bridge
- Static site integration
- ActivityPub support
- Self-hosted deployment
- Rust-based backend
- Docker support

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted via Docker or from source.
