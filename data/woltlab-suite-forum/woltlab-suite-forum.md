## Overview

WoltLab Suite Forum is an Internet forum software package written in PHP, part of the WoltLab Suite platform for building online communities.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL
- License: Proprietary (Forum); LGPL 2.1 (Core)
- Creator: WoltLab GmbH
- Latest release: 6.1.7 (2025-04-15)

## Deployment

Self-hosted.
