## Overview

Iceshrimp.NET is a federated microblogging server that communicates over ActivityPub.

## Features

- Federated microblogging
- ActivityPub protocol
- Self-hosted deployment
- .NET/C# backend
- Docker support

## Pricing

Free and open-source under the EUPL-1.2 license.

## Deployment

Self-hosted via Docker or from source.
