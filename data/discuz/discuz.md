## Overview

Discuz! is a proprietary Internet forum software package written in PHP, developed by Comsenz Inc.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL
- License: Proprietary
- Creator: Comsenz Inc.
- Latest release: X3.5 (2022-12-31)
