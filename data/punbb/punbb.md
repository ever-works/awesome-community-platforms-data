## Overview

PunBB is an open-source Internet forum software package written in PHP, designed to be fast and lightweight.

## Technical Details

- Programming language: PHP
- Supported databases: MySQL, PostgreSQL, SQLite
- License: GNU General Public License (GPL)
- Creator: PunBB
- Latest release: 1.4.6 (2021-03-09)

## Deployment

Self-hosted.
