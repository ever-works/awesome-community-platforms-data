## Overview

Scoold is Stack Overflow in a JAR, an enterprise-ready Q&A platform with full-text search, SAML, LDAP integration and social login support.

## Features

- Q&A platform
- Full-text search
- SAML integration
- LDAP integration
- Social login support
- Enterprise-ready
- Self-hosted deployment
- Java-based backend
- Docker support
- Kubernetes support

## Pricing

Free and open-source under the Apache-2.0 license.

## Deployment

Self-hosted via Docker, Kubernetes, or from source.
