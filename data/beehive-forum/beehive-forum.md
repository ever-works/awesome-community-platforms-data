## Overview

Beehive Forum is an open-source Internet forum software package written in PHP.

## Technical Details

- Programming language: PHP
- Supported databases: MySQL
- License: GNU General Public License (GPL)
- Creator: Project Beehive Forum Developers
- Latest release: 1.5.2 (2016-11-05)
