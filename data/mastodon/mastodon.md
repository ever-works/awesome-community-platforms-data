## Overview

Mastodon is a federated microblogging server that allows users to run their own instance and interact across the ActivityPub network.

## Features

- Federated microblogging
- ActivityPub protocol
- Self-hosted deployment
- Ruby-based backend

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted from source.
