## Overview

Artalk is a comment system built in Golang that provides a lightweight and highly customizable solution for adding comments to your website.

## Features

- Lightweight commenting system
- Highly customizable
- Self-hosted deployment
- Go-based backend
- Docker support

## Pricing

Free and open-source under the MIT license.

## Deployment

Self-hosted via Docker or from source.
