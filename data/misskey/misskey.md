## Overview

Misskey is a decentralized app-like microblogging server/SNS for the Fediverse, using the ActivityPub protocol like GNU social and Mastodon.

## Features

- Decentralized microblogging
- ActivityPub protocol
- Fediverse compatibility
- Self-hosted deployment
- Node.js backend
- Docker support

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted via Docker or from source.
