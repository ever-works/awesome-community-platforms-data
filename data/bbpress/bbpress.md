## Overview

bbPress is an open-source forum software package designed as a plugin for WordPress, allowing users to add discussion forums to a WordPress site.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL
- License: GNU General Public License (GPL)
- Creator: WordPress Foundation
- Latest release: 7.1.2 (2026-09-22)

## Deployment

Self-hosted; installed as a WordPress plugin on PHP-capable web servers.
