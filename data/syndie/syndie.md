## Overview

Syndie is an open-source Internet forum software package related to the I2P anonymous network, written in Java.

## Technical Details

- Programming language: Java
- License: Open source, multiple licenses
- Creator: Anonymous (related to I2P)
- Latest release: 1.107b (2016-08-14)

## Deployment

Self-hosted.

## Pricing

Free and open-source under multiple open source licenses.
