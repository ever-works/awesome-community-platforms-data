## Overview

Invision Community, formerly known as Invision Power Board (IPB), is a proprietary Internet forum software package written in PHP.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL
- License: Proprietary
- Creator: Invision Power Services Inc.
- Latest release: 4.7.19 (2024-11-12)

## Deployment

Self-hosted (with cloud hosting options available commercially).

## Pricing

Paid commercial license.
