## Overview

Phorum is an open-source Internet forum software package written in PHP. It is designed for creating online discussion forums with support for flat and threaded message views.

## Features

- Flat vs. threaded view: Supports both flat and threaded discussion modes
- User-selectable themes: Yes
- Unread message tracking: Full (persistent database tracking of read/unread status per user)
- WYSIWYG Editor: Yes
- Export and portability: Yes
- Email/NNTP interface: Plugin support available
- Single sign-on (SSO): No
- Draft saving: Supported

## Deployment

Self-hosted, PHP-based forum software.
