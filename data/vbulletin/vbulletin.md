## Overview

vBulletin is a proprietary Internet forum software package written in PHP, widely used for building online communities and discussion forums.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL
- License: Proprietary
- Creator: vBulletin Solutions Inc.
- Latest release: 6.2.0 (2026-03-12)

## Deployment

Self-hosted.

## Pricing

Paid commercial license.
