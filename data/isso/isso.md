## Overview

Isso is a lightweight commenting server written in Python and Javascript, designed as a drop-in replacement for Disqus.

## Features

- Lightweight commenting server
- Disqus replacement
- Self-hosted deployment
- Python-based backend
- Docker support

## Pricing

Free and open-source under the MIT license.

## Deployment

Self-hosted via Docker or from source.
