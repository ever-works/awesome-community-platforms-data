## Overview

Simple Machines Forum (SMF) is an open-source Internet forum software package written in PHP.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL, PostgreSQL
- License: BSD License
- Creator: Simple Machines
- Latest release: 2.1.7 (2026-03-08)

## Deployment

Self-hosted.
