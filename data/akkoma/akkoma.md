## Overview

Akkoma is a federated microblogging server compatible with Mastodon, GNU social, and ActivityPub. It allows users to run their own social networking instance and interact with the wider fediverse.

## Features

- ActivityPub federation
- Mastodon API compatibility
- GNU social compatibility
- Self-hosted deployment
- Elixir-based backend
- Docker support

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted via Docker or from source.
