## Overview

PieFed is a link aggregator / reddit clone for the fediverse, serving as an alternative to Reddit.

## Features

- Link aggregator
- Reddit alternative
- Fediverse compatibility
- Self-hosted deployment
- Python-based backend
- Docker support

## Pricing

Free and open-source under the AGPL-3.0 license.

## Deployment

Self-hosted via Docker or from source.
