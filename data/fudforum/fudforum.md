## Overview

FUDforum is an open-source Internet forum software package written in PHP with support for multiple database backends.

## Technical Details

- Programming language: PHP
- Supported databases: MariaDB, MySQL, Oracle, PostgreSQL, SQLite
- License: GNU General Public License (GPL)
- Creator: Advanced Internet Designs Inc.
- Latest release: 3.2.1 (2026-06-14)

## Deployment

Self-hosted.
