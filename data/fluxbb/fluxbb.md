## Overview

FluxBB is an open-source, lightweight Internet forum software package written in PHP.

## Technical Details

- Programming language: PHP
- Supported databases: MySQL, PostgreSQL, SQLite
- License: GNU General Public License (GPL)
- Creator: FluxBB.org Developers
- Latest release: 1.5.11 (2018-12-31)

## Deployment

Self-hosted.
